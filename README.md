# ComputerVision
Individual Assignment 1

——18/10/2024 


A project that convert spoken Cantonese characters to written Mandarin characters (all traditional Chinese) making Cantonese learners know the meaning of a post completely.


### What materials you need?
---- A screenshot of characters from Xiaohongshu (Why Xiaohongshu: the reason is content of a post can not be copied directly on this platform)
---- Other materials you can download following the code.
